# Sistema de Gerenciamento de Tarefas (ToDo List)

Este projeto é um sistema web simples para gerenciamento de tarefas, desenvolvido em Django.

## Funcionalidades
- Listagem de tarefas
- Visualização de detalhes de uma tarefa
- Criação de nova tarefa
- Edição de uma tarefa
- Exclusão de uma tarefa

## Instruções de Execução
1. Clone o repositório:
   ```sh
   git clone <URL_DO_REPOSITORIO>
   ```
2. Crie e ative o ambiente virtual:
   ```sh
   python -m venv venv
   .\venv\Scripts\activate
   ```
3. Instale as dependências:
   ```sh
   pip install -r requirements.txt
   ```
4. Execute as migrações:
   ```sh
   python manage.py migrate
   ```
5. Inicie o servidor:
   ```sh
   python manage.py runserver
   ```
6. Acesse o sistema em [http://localhost:8000](http://localhost:8000)
