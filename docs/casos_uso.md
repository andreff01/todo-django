# Diagrama de Casos de Uso

![Diagrama de Casos de Uso](casos_uso.png)

Caso não tenha a imagem, adicione aqui um diagrama simples representando os casos de uso:

- Listar tarefas
- Visualizar tarefa
- Criar tarefa
- Editar tarefa
- Excluir tarefa

Cada ator (usuário) pode realizar todas as ações acima.
