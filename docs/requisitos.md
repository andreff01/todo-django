# Documento de Requisitos

## Requisitos Funcionais
- RF01: O sistema deve permitir ao usuário listar todas as tarefas cadastradas.
- RF02: O sistema deve permitir ao usuário visualizar os detalhes de uma tarefa.
- RF03: O sistema deve permitir ao usuário criar uma nova tarefa.
- RF04: O sistema deve permitir ao usuário editar uma tarefa existente.
- RF05: O sistema deve permitir ao usuário excluir uma tarefa.

## Requisitos Não Funcionais
- RNF01: O sistema deve ser desenvolvido utilizando Django.
- RNF02: O sistema deve ser acessível via navegador web.
- RNF03: O sistema deve armazenar os dados em banco de dados SQLite.
